# ArduinoSensorMiddleware (Arsemi/arsemi/ArSeMi)

Arsemi is a C# package for easily managing sensors and sampling from a C# script. Digital, analog and some selected I2C sensors can be interfaced.


## Usage

To learn how to use Arsemi visit the repository's wiki: https://github.com/Mikagino/ArduinoSensorMiddleware/wiki
